# Шаблон презентации митапа MoscowCSS

Шаблон открывающей презентации митапа на [Slidev](https://sli.dev), выделенный из
`Moscow_open.pdf`. Вся вёрстка описана переиспользуемыми layout'ами — на каждый митап
меняется только контент в `slides.md`, дизайн остаётся неизменным.

## Запуск

```bash
pnpm install
pnpm dev        # редактирование с live-reload → http://localhost:3030
pnpm build      # статическая сборка в dist/
pnpm export     # PDF (требует playwright, см. ниже)
```

## Структура

```
slides.md         ← единственный файл, который правят на каждый митап
style.css         ← токены темы (цвета, шрифт)
layouts/          ← 6 переиспользуемых вёрсток
public/
  logo.svg        ← логотип-башенка (вектор)
  qr/             ← QR-коды: announce, chat, talk, questions, school21
  img/            ← фото спикеров
```

## Готовые и меняющиеся слайды

| № | Layout | Слайд | Правка |
|---|--------|-------|--------|
| 1 | `cover` | Обложка | только номер митапа `**30**` |
| 2 | `statement` | Приветствие | номер |
| 3 | `qr-side` | Спонсор/площадка | под партнёра |
| 4 | `qr-trio` | Три QR (анонсы/чат/доклад) | **не меняется** |
| 5 | `statement` | «Спасибо спикерам» | **не меняется** |
| 6–8 | `speaker` | Спикеры | заполнить каждого |
| 9 | `statement` | Число докладов | число |
| 10 | `logo-side` | Секретная активность | текст |
| 11 | `qr-side` | Вопросы в чат | **не меняется** |
| 12–13 | `statement` | «Вы готовы?» / «Мы начинаем» | **не меняется** |

## Как менять контент

Всё редактируется во frontmatter слайда (между `---`) в `slides.md`.

**Добавить/сменить спикера:**

```md
---
layout: speaker
name: Имя Фамилия
role: Кто по роли
photo: /img/speaker-1.png     # положить фото в public/img/
pitch: О чём коротко расскажет
talk: 'Название доклада без кавычек — «ёлочки» добавит шаблон'
---
```

**Крупная фраза по центру** (`statement`): текст прямо в теле слайда, перенос — `<br>`,
красный акцент — `[текст]{.accent}`.

**Слайд с QR сбоку** (`qr-side`): `qr:` — путь к картинке, `title:` — заголовок,
тело слайда — описание.

## Дизайн-токены (`style.css`)

| Токен | Значение | Назначение |
|-------|----------|------------|
| `--mcss-bg` | `#121212` | фон |
| `--mcss-fg` | `#ffffff` | заголовки |
| `--mcss-body` | `#e8e8e8` | основной текст |
| `--mcss-muted` | `#8a8a8a` | подписи, роли |
| `--mcss-accent` | `#ca3035` | красный: звезда, `CSS`, `#вопрос` |

Шрифт: **Montserrat** (геометрический гротеск с кириллицей) — бесплатная замена
платного Avenir Next из оригинала. Меняется в headmatter `slides.md` (`fonts.sans`).

## Экспорт в PDF

`slidev export` рендерит через Playwright:

```bash
pnpm add -D playwright-chromium
pnpm exec playwright install chromium
pnpm export
```

Без установки Playwright можно открыть `pnpm dev` → `http://localhost:3030/export/`
и распечатать в PDF из браузера.

## Генератор QR-кодов

QR в фирменном стиле (белые кружки, кольцевые «глазки», логотип-башенка по центру,
тёмный фон) генерируются командой `qr` — в SVG, готовый для слайдов:

```bash
pnpm qr <url> [имя]

pnpm qr https://css.moscow site          # → public/qr/site.svg
pnpm qr https://t.me/moscowcss chat       # → public/qr/chat.svg
```

Флаги: `--out путь.svg` (свой путь), `--bg none` (прозрачный фон), `--no-logo`
(без башенки по центру), `--fg #ffffff` (цвет модулей), `--logo 0.24` (доля под логотип).

Код использует уровень коррекции ошибок **H** (30%), поэтому логотип по центру не мешает
сканированию. QR светлый-на-тёмном (как оригиналы) — телефоны такие читают.

Проверка сканируемости: `pnpm test:qr` (рендерит и декодирует через zbarimg).

## Ассеты

QR-коды, фото спикеров и логотип извлечены из `Moscow_open.pdf`. QR анонсов, чата и
подачи доклада — постоянные, лежат в `public/qr/` и переиспользуются между митапами.
Обновить QR — заменить файл в `public/qr/` (или сгенерировать заново командой `qr`),
имя оставить прежним.
